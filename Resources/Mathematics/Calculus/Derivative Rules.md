>Let $c$ and $n$ be real numbers.
>Let $f$ and $g$ represent functions of the independent variable $x$.

| Rule                              | Function           | Derivative                                                                         |
| --------------------------------- | ------------------ | ---------------------------------------------------------------------------------- |
| Derivative of a Constant          | $y(x)=c$           | $y'(x)=\frac{dy}{dx}=\frac{d}{dx}(c)=0$                                            |
| Power Rule                        | $y(x)=x^n$         | $y'(x)=\frac{dy}{dx}=\frac{d}{dx}(x^n)=nx^{n-1}$                                   |
| Derivative of a Constant Multiple | $y(x)=c \cdot f$   | $y'(x)=\frac{dy}{dx}=\frac{d}{dx}(c \cdot f = c \cdot f'$                          |
| Sum Rule                          | $y(x)=(f+g)$       | $y'(x)=\frac{dy}{dx}=\frac{d}{dx}(f+g)=f'+g'$                                      |
| Difference Rule                   | $y(x)=(f-g)$       | $y'(x)=\frac{dy}{dx}=\frac{d}{dx}(f-g)=f'-g'$                                      |
| Natural Exponential Function      | $y(x)=e^x$         | $y'(x)=\frac{dy}{dx}=\frac{d}{dx}(e^x)=e^x$                                        |
| Product Rule                      | $y(x) = f \cdot g$ | $y'(x)=\frac{dy}{dx}=\frac{d}{dx}(f\cdot g)=f \cdot g' + f' \cdot g$               |
| Quotient Rule                     | $y(x)=\frac{f}{g}$ | $y'(x)=\frac{dy}{dx}=\frac{d}{dx}(\frac{f}{g})=\frac{g\cdot f' - f \cdot g'}{g^2}$ |
