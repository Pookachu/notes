Question IC-4
$$\begin{aligned}
f'(x) &= \frac{d}{dx}(49x^2 - 28x + 4) \\\\ 
&= 49(2x) - 28(1) + 0 \\
&= 98x - 28 
\end{aligned}$$

An alternative way to solve this is to use the **[[Chain Rule]]** on the original function, which gets the same result:$$f'(x) = 2(7x-2)^1 \cdot \frac{d}{dx}(7x-2) = 2(7x-2)(7) = 14(7x-2) = 98x - 28$$
