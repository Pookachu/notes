$$\begin{aligned}
f'(x) &= \frac{d}{dx}(49x^2 - 28x + 4) \\\\ 
&= 49(2x) - 28(1) + 0 \\
&= 98x - 28 
\end{aligned}$$

An alternative way to solve this is to use the **[[Chain Rule]]** on the original function, which gets the same result:$$f'(x) = 2(7x-2)^1 \cdot \frac{d}{dx}(7x-2) = 2(7x-2)(7) = 14(7x-2) = 98x - 28$$

**Question 5:**
>Find the derivative of the following function by first expanding or simplifying the expression.	 
>	$g(w) = \frac{4e^{2w}+7e^w}{e^w}$
$$\begin{aligned}
g(x)=& \frac{4e^{2w}}{e^w}+\frac{7e^w}{e^w} = 4e^{2w-w}+{7e^{w-w}}=\boxed{4e^{w}+7} \\\\
g'(x)=4e^w
\end{aligned}$$

**Question 7:**
> Find the derivative of the function:
> 	$y=\sqrt[7]{x^6}-x^{\sqrt{2}}$

$$\begin{aligned}
y&=x^{6\over7}-x^{\sqrt2} \\
y'&={6\over7}x^{-1\over7}-\sqrt{2}x^{\sqrt2-1}
\end{aligned}$$
