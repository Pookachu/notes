The general rule for differentiating an exponential function with any base a is:
$${d\over dx}(a^u)=a^u\cdot\ln(a)\cdot{du \over dx}$$

Example: Find ${dy\over dx}$ for $\log_a x=y$ $\quad\Leftrightarrow\quad$ $a^y=x$
Use implicit differentiation for $a^y=x$

1. Find the derivative of $y=3^{\sqrt w}$
$$\begin{gather}
{dy\over dw} = 3^{\sqrt w} \ln3 {1\over 2\sqrt w} \\
=\boxed{\frac{3^{\sqrt w} \ln3}{2\sqrt w}}
\end{gather}$$
2. Find the derivative of y with respect to z.
$y=3^{z^3}$
$${dy\over dz}=3^{z^3}\cdot\ln3\cdot3z^2$$

3. Find the derivative of $y$ with respect to $x$.
$y=10\ln(\sin x)$
$$\begin{gather}
{dy\over dx} = 10 {d\over dx}\ln(\sin x) = {1\over\sin x}\cos x \\\\
= 10\cot x
\end{gather}$$
4. Find the derivative of $y$ with respect to $t$.
$y=\ln(9te^{-8t})$
$$\begin{gather}
{dy\over dt} = {1\over9te^{-8t}} \cdot9{d\over dt}te^{-8t} \\\\
= {1\over9te^{-8t}}\cdot9(e^{-8t}+t{d\over dt}e^{-8t}) \\\\
= {1\over9te^{-8t}}\cdot9(e^{-8t}+-8te^{-8t}) \\\\
\text{OR} \\\\
y = \ln(9)+\ln(t)+\ln(e^{-8t}) \\\\
y = \ln(9) +\ln(t) -8t \\\\
{dy\over dt} = 0 + \boxed{{1\over t} -8}
\end{gather}$$

Example: Find ${dy\over dx}$ for $\log_a x=y$ $\quad\Leftrightarrow\quad$ $a^y=x$
Use implicit differentiation for $a^y=x$

3. Find the derivative of $y$ with respect to $r$.
$y=log_3 r\cdot \log_5 r$
$$\begin{aligned}
y &= {\ln r \over \ln 3} \cdot {\ln r \over \ln 5} \\\\
y &= {1\over \ln 3 \ln 5}\cdot\ln^2 r \\\\
{dy\over dr} &=  {1\over \ln 3 \ln 5} {d\over dr}\ln^2 r \\\\
&= {1\over \ln 3 \ln 5}\cdot2\ln r \cdot {1\over r} \\\\
&= \frac{2\ln r}{r\ln3 \ln5}
\end{aligned}$$

4. Find the derivative of $y$ with respect to the given independent variable.
$y=\theta \sin (\log_3 \theta)$
$$\begin{gather}
{dy\over d\theta} = {d\over d\theta}(\sin(\log_3\theta))\theta + {d\over d\theta}\theta \sin(\log_3 \theta) \\\\
{d\over d\theta}\sin(\log_3\theta) = \cos(\log_3\theta) {d\over d\theta}\log_3\theta \\\\
{d\over d\theta}\log_3\theta={d\over d\theta}{\ln \theta \over \ln 3} = {1\over \ln3}{d\over d\theta}\ln \theta = {1\over\theta\ln3} \\\\
{dy\over d\theta}=\cos(\log_3\theta){1\over\ln3}+\sin(\log_3\theta) \\\\
\end{gather}$$
