Find $ds\over dt$ if $s={t\over7t+2}$
[[Derivative Rules]]
$$\begin{gather}
\frac{(\frac{t+h}{7(t+h)+2})-(\frac{t}{7t+2})}{h} = \frac{\frac{t+h}{7t+7h+2}-\frac{t}{7t+2}}{h} \\\\
= \frac{\frac{(t+h) (7t+2)}{(7t+7h+2) (7t+2)}-\frac{t(7t+7h+2)}{(7t+7h+2)(7t+2)}}{h} \\\\
= \frac{\frac{(t+h) (7t+2)-(t(7t+7h+2))}{(7t+7h+2) (7t+2)}}{h} \\\\
= \frac{\frac{(7t^2+7th+2t+2h)-(7t^2+7th+2t)}{(7t+7h+2) (7t+2)}}{h} \\\\
= \frac{\frac{2h}{(7t+7h+2) (7t+2)}}{h} \\\\
= \lim_{h\to 0}\frac{2}{(7t+7h+2) (7t+2)} \\\\
= \frac{2}{(7t+2)(7t+2))} = \boxed{\frac{2}{49t^2+28t+4}}\\\\
\end{gather}$$
