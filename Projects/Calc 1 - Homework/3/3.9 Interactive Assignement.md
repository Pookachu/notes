Section 3.9 Inverse trig functions
Derivatives of inverse trigonometric functions

| **1** ${d\over dx}(\arcsin x) = {1\over \sqrt{1-x^2}}\quad(\vert x\vert < 1)$               | **4.**${d\over dx}(\arccos x) = -{1\over\sqrt{1-x^2}}\quad(\vert x\vert < 1)$                |
| ------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| **2.**${d\over dx}(\arctan x)= {1\over1+x^2}$                                               | **5.**${d\over dx}(\text{arccot }x)=-{1\over1+x^2}$                                          |
| **3.**${d\over dx}(\text{arcsec } x)={1\over\vert x\vert\sqrt{x^2-1}}\quad(\vert x\vert>1)$ | **6.**${d\over dx}(\text{arccsc } x)=-{1\over\vert x\vert\sqrt{x^2-1}}\quad(\vert x\vert>1)$ |
1. Find the derivative of $y$ with respect to $t$.
$y= \arccos(\sqrt{11}t)$

$$\begin{aligned}
{dy \over dt} &= -{1\over\sqrt{1-(\sqrt{11}t)^2}}\cdot\sqrt{11}{d\over dt}t \\\\
&= -\frac{\sqrt{11}}{\sqrt{1-(\sqrt{11}t)^2}} \\\\
&= \boxed{-\frac{\sqrt{11}}{\sqrt{1-11t^2}}}
\end{aligned}$$

2. Find the derivative of $y$ with respect to $s$.
$y=\text{arcsec}(2s^3+5)$
$$\begin{aligned}
{dy \over ds} &= \frac{6s^2}{|2s^3+5|\sqrt{(2s^3+5)^2-1}}
\end{aligned}$$

3. Find the derivative of $y$ with respect to $t$.
$y=\text{arccot}\sqrt{11t}$
$$\begin{aligned}
{dy \over dt} &= -\frac{\sqrt{11} {1\over 2\sqrt t}}{1+11t} \\\\
&= -\frac{\sqrt{11}}{2\sqrt{t}(1+11t)}
\end{aligned}$$

4. Find the derivative of $y$ with respect to $x$.
$y=\ln(\tan^{-1}(7x^3))$
$$\begin{aligned}
{dy \over dx} &= {1\over tan^{-1}(7x^3)} {21x^2 \over 1+(7x^3)^2} \\\\
&= {21x^2 \over (1+49x^6)tan^{-1}(7x^3)}
\end{aligned}$$

5. Find the derivative of $y$ with respect to $x$.

$y= \tan^{-1}\sqrt{x^2-1}-csc^{-1}x\quad x>1$

$$\begin{aligned}
{dy\over dx} &= \frac{{d \over dx}\sqrt{x^2-1}}{x^2} +{1\over|x|\sqrt{x^2-1}} \\\\
&= \frac{{1\over2}(x^2-1)^{-{1\over2}}2x}{x^2}+{1\over|x|\sqrt{x^2-1}} \\\\
&= { 1\over x\sqrt{x^2-1}}+{1\over|x|\sqrt{x^2-1}} \quad\text{x>1} \\\\
&= \boxed{\frac{2}{x\sqrt{x^2-1}}}
\end{aligned}$$
