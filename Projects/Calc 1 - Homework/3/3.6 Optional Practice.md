7.
Find the derivative of the function $y= (\csc x + \cot x)^{-1}$
$$\begin{gather}
{dy\over dx} = -(\csc x + \cot x)^-2\cdot{d\over dx}(\csc x + \cot x) \\
= -\frac{1}{(\csc x + \cot x)^2}(-\csc x \cot x -\csc^2x) \\
= \frac{\csc x \cot x -\csc^2x}{(\csc x + \cot x)^2}
\end{gather}$$

Find the derivative of the function $y=(\csc x -\cot x)^{-1}$
$$\begin{gather}
{dy\over dx} = -\frac{1}{(\csc x -\cot x)^2}\cdot{d\over dx}(\csc x -\cot x) \\\\
= -\frac{1}{(\csc x -\cot x)^2}(-\csc x\cot x+\csc^2x) \\\\
= \frac{\csc x \cot x - \csc^2x}{(\csc x - \cot x)^2} \\\\
= \frac{-\csc x(\csc x -\cot x)}{(\csc x - \cot x)^2} \\\\
= \frac{-\csc x}{ \csc x -\cot x}
\end{gather}$$
