4. For what values of $a$ is the following function continuous at every $x$? 
$$ f(x) = \begin{cases}
a^2x-2a,\quad x \geq 2 \\
40,\quad\quad\quad x\lt 2
\end{cases}$$
Solution:
$$\begin{aligned}
&\text{Set both sides equal to each other}\\
&\to\quad a^2x-2a = 40 \\
&\text{At the point we're concerned about $x=2$}\\
&\to\quad 2a^2-2a=40 \quad\to\quad 2a^2-2a-40=0 \\
&\text{Factor}\\
&\to\quad u\cdot v=80,\; u+v = -2\\
&\to\quad (2a^2-10a)+(8a-40)=0 \\
&\to\quad 2a(a-5)+8(a-5) =0 \\
&\to\quad (2a+8)(a-5) \quad\to\quad2(a+4)(a-5)=0 \\
&\to\quad 0 = \boxed{-4,\;5}
\end{aligned}$$
5. Let $f(x)=\frac{x^2-22}{x^2-x-2}$ and $g(x)=\frac{1}{x+1}$. Using properties and direct calculation, determine the points at which each of the following functions are discontinuous.
Solution: $$\begin{aligned}
&\text{The function $f$ is discontinuous at:} \\
&\to\quad x^2-x-2=0 \quad\to\quad(x^2-2x)+(x-2) \\
&\to\quad x(x-2)+1(x-2) \quad\to\quad (x+1)(x-2) \\
&\to\quad \boxed{-1,\;2} \\\\
&\text{The function $g$ is discontinuous at:}\\
&\to\quad \boxed{-1}\\\\
&\text{The function f+g is discontinuous at:}\\
&\to\quad \frac{(x^2-22)(x+1)+x^2-22}{(x^2-x-2)(x+1)}\\
&\to\quad \boxed{-1,\;2} \\
&\text{And that's the same for the rest of the questions.}
\end{aligned}$$
